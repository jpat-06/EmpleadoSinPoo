# Sistema de cálculo de sueldo de empleados (Java)

Este proyecto es una aplicación de consola desarrollada en Java que permite
registrar el nombre de un empleado, las horas trabajadas y calcular su sueldo
mensual en base a un valor por hora, incluyendo bonos y descuentos.

## Funcionalidades
- Ingreso de datos del empleado por consola
- Cálculo de sueldo base según horas trabajadas
- Aplicación de bono y bono escolar
- Aplicación de descuento
- Visualización del sueldo final

## Tecnologías utilizadas
- Java
- Maven
- Git / GitHub

## Aprendizajes
- Uso de variables y tipos de datos en Java
- Entrada de datos por consola con Scanner
- Aplicación de lógica de negocio
- Buenas prácticas básicas de nombres de variables
- Uso de Git y GitHub para control de versiones
